# Protocol: sunblink

Sunblink backend for Hello Kitty Island Adventure (Sunblink / Sanrio, Switch, Unity), the only
known title. No hosts, endpoints or wire formats are recorded yet; no code exists until the
captures in [evidence-needed.md](evidence-needed.md) show what the Switch build dials.

What is known ([design.md](design.md)): multiplayer is 2-player visit-a-friend with temporary
invite codes, no cross-platform play, Nintendo Switch Online required. It is not NEX or NPLN
(no Nintendo game-server strings expected), and no Photon, PlayFab, EOS, Demonware, Klei, Team17
or Battle.net AppId, tenant or hostname has been observed for it. A Sunblink rendezvous plus
peer/relay session is a hypothesis only.
